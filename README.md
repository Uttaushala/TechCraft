# TechCraft

Технический мод для **Minecraft 1.12.2 / Forge** (14.23.5.2860+): энергия и машины.
Энергия — стандартная **Forge Energy (FE)**, совместимая с RF, поэтому машины работают
с проводами, генераторами и хранилищами других модов в сборке (Thermal, Mekanism, EnderIO и т.д.).

## Содержимое

| Блок | Что делает |
|------|------------|
| **Угольный генератор** | Сжигает любое печное топливо (уголь, дерево, ведро лавы…), даёт 40 FE/тик, отдаёт энергию во все соседние блоки |
| **Электропечь** | Переплавляет всё, что умеет обычная печь, за 20 FE/тик (быстрее печи: 5 сек на предмет) |
| **Дробитель** | Руда → 2 пыли (удвоение руды), слиток → пыль, булыжник → гравий → песок, кость → 6 костной муки и др. Автоматически подхватывает руды и пыли других модов через Ore Dictionary |
| **Аккумуляторный блок** | Хранит 1 000 000 FE. Принимает энергию со всех сторон, отдаёт через **лицевую** сторону |

Предметы: железная и золотая пыль (переплавляются в слитки), простая схема, каркас машины.

Все машины:
- подсвечиваются и меняют текстуру во время работы;
- поддерживают воронки/трубы (вход — сверху/сбоку в слот ввода, выход забирается из слота вывода);
- настраиваются через конфиг `config/techcraft.cfg` (или в игре: Mods → TechCraft → Config).

## Рецепты (крафт)

- **Простая схема** ×2: редстоун сверху и снизу, в середине `железо – золотой самородок – железо`
- **Каркас машины**: 8 железных слитков вокруг редстоуна
- **Угольный генератор**: `Ж С Ж / Ж К Ж / Ж П Ж` (Ж — железо, С — схема, К — каркас, П — печь)
- **Электропечь**: `Ж С Ж / П К П / Ж Р Ж` (Р — редстоун)
- **Дробитель**: `Ж Кр Ж / С К С / Ж Пр Ж` (Кр — кремень, Пр — поршень)
- **Аккумуляторный блок**: `Ж С Ж / Б К Б / Ж Б Ж` (Б — блок редстоуна)

Если в сборке есть JEI, все рецепты крафта будут видны в нём.

## Как начать

1. Поставьте угольный генератор и положите в него уголь.
2. Вплотную к генератору поставьте электропечь или дробитель — энергия пойдёт сама.
3. Для запаса энергии: генератор → аккумуляторный блок (лицом к машине) → машина.

## Установка в сборку

Скачайте `techcraft-1.12.2-<версия>.jar` и положите в папку `mods` вашей сборки.

Готовый jar собирается автоматически на GitHub: вкладка **Actions** → последний запуск
**Build** → артефакт **techcraft-mod** (zip с jar-файлом внутри).

## Сборка вручную

Нужна **Java 8** (JDK). Затем:

```bash
./gradlew setupDecompWorkspace   # один раз
./gradlew build
```

Готовый мод появится в `build/libs/`.
Запуск клиента для разработки: `./gradlew runClient`.
